# Jazzy Kali Toolkit

Kali ke command-line tools ke liye GUI frontend — command yaad rakhne ki zaroorat nahi!

## Chalane ka tarika

```bash
sudo python3 jazzy_kali_toolkit.py
```

(Kuch features jaise monitor mode ke liye root chahiye. Tkinter Kali me pehle se hota hai — kuch install nahi karna.)

## Tabs

1. **Nmap Scan** — Target IP daalo, scan type chuno (Quick / Full ports / OS detect / Service versions / Aggressive / Ping only), Run dabao. Output live dikhega.
2. **WiFi Audit** — Interface select karo → Monitor mode ON/OFF ya airodump-ng se networks scan karo.
3. **Metasploit** — msfconsole command likho (jaise `search type:exploit platform:linux`), Run dabao.

## Note

Sirf apne lab / apne network pe use karo. 🔒
